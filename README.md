# Proyecto DB24 - Alaca

## Descripcion 
- Dessarrollo un sitema que se encarga de la gestion de un almacen. Para poder automatizar el manejo de carga de productos, y agilizar las ventas.

## Integrantes
- Alaca Yael

## Caracteristicas 
- Motor de base de datos: MYSQL
- Tecnologia utilizadas: lenguaje de programacion java, trabajando con componentes swing.
- Funcionalidades principales:
    - El usuario inicia sesion (administrador/ empleado)
    - Registra usuarios, modifica e elimina.
    - Registra productos, modifica e elimina
    - Registra proveedores, modifica e elimina
    - Registra ventas 
    - Muestra por pantalla el registro tanto de Usuarios, Producto, Proveedores y Ventas, cada registro se muestra a traves de diferentes tablas.
